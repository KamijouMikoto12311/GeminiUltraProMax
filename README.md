# GeminiUltraProMax

一个用元素周期表选择虚构 AI 模型的交互界面演示，支持元素搜索、分类筛选及放射性元素状态。

这是个人制作的非官方演示项目，与 Google 无隶属、合作或背书关系。页面没有接入真实 AI 对话服务。

## 本地查看

在浏览器中打开 `index.html`。样式和字体通过页面中声明的外部资源加载。

## 发布

GitHub Pages 使用 `main` 分支的仓库根目录 `/` 发布，网站首页为 `index.html`。
